# Lexique du diaporama v20

| Terme | Sens dans Spity |
| --- | --- |
| Projet solo | Dorian réalise le projet ; les responsabilités ne désignent pas plusieurs salariés. |
| Jour-personne (j-h) | Unité de charge : une personne pendant une journée. Ce n’est pas une durée calendaire. |
| Prévisionnel | Estimation avant réalisation ; ici les charges et coûts du Bloc 1. |
| Consommé | Temps ou argent réellement utilisé, à justifier. Non fourni dans ce kit. |
| Backlog | Liste des sujets restant à traiter. |
| Ticket | Sujet de travail avec un statut ; sa taille varie. |
| Commit / SHA | Version enregistrée du code et son identifiant. |
| Pull request / PR | Ensemble de changements proposés avant intégration dans la branche principale. |
| CI / CD | Contrôles automatiques puis mécanisme de livraison. |
| Build standalone | Application compilée et préparée pour être exécutée. |
| Recette | Vérification des parcours contre des critères définis. |
| Médiane | Valeur centrale après tri ; ici la troisième de cinq mesures de parcours. |
| Persona simulé | Profil inventé pour illustrer un besoin, pas une personne interviewée. |
| Réception | Décision sur le résultat livré ; aucune réception réelle n’est jointe. |
| Réserve | Point qui reste à corriger ou vérifier après une démonstration. |
| Rétrospectif | Analyse faite après les changements, à partir des traces disponibles. |

Un test technique, un statut Linear et un avis utilisateur ne prouvent pas la même chose. Conserver la source, la date et la portée de chaque information.
