# Documentation Spity

Cette arborescence est la source unique des livrables projet et RNCP.

> Pour une entrée de lecture orientée jury, commencer par [`../JURY.md`](../JURY.md).

## Organisation

- [`audits/`](audits) : états des lieux datés et décisions de remise en ordre ;
- [`rncp/bloc-01/`](rncp/bloc-01) : livrables HTML, PDF et sources du bloc 1 ;
- [`rncp/bloc-02/`](rncp/bloc-02/README.md) : dossier final du bloc 2, annexes et plan initial archivé ;
- [`rncp/bloc-03/`](rncp/bloc-03/README.md) : kit Bloc 3 — dossier, support oral, pilotage, annexes et démonstration vérifiée ;
- [`rncp/bloc-04/`](rncp/bloc-04) : dossier, revue finale, preuves et [parcours jury](rncp/bloc-04/dossier-jury/README.md) du bloc 4 ;
- [`rncp/referentiel/`](rncp/referentiel) : référentiel officiel utilisé pour contrôler les attendus.

Le cadrage produit reste à la racine dans [`CADRAGE_PROJET.md`](../CADRAGE_PROJET.md), tandis que la documentation exécutable propre à l'application reste dans [`spity/`](../spity).

Les quatre blocs sont regroupés dans `rncp/`. Les exports prêts à remettre se trouvent dans [`output/`](../output/README.md). Les procédures techniques sont indexées dans [`spity/docs/`](../spity/docs/README.md).
