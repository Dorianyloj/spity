# Exploitation de Spity

Les commandes s'exécutent depuis `spity/` à la racine du dépôt, ou depuis le bundle de release lorsque le guide le précise.

| Besoin | Guide |
| --- | --- |
| Installer et déployer | [Déploiement](DEPLOYMENT.md) et [VPS](../../deploy/README.md) |
| Maintenir les dépendances | [Maintenance](MAINTENANCE.md) |
| Surveiller le service | [Observabilité](OBSERVABILITY.md) |
| Traiter un incident | [Gestion des incidents](INCIDENT_MANAGEMENT.md) |
| Planifier une amélioration | [Gestion des améliorations](IMPROVEMENT_MANAGEMENT.md) |
| Vérifier une version déployée | [Vérification des releases](RELEASE_VERIFICATION.md) |
| Consulter ou tenir le journal des versions | [Journal des releases](RELEASE_JOURNAL.md) |
| Répondre au support | [Support](SUPPORT.md) |
| Administrer les contenus | [Administration](admin.md) |

Les politiques JSON et les registres restent dans le dossier applicatif ; les scripts et la CI les contrôlent. Ce répertoire rassemble leurs procédures.
